# Manual environment probe

Include `probe.hpp` in a manually linked GPU example runner and call `runEnvironmentProbe(engine, engineShaderRoot, absentHDRPath)` with an initialized draw Engine, producers stopped and no active frame. No target/CMake change is added. Compile the paired `draw/environment` shaders through the existing build integration. The agent has not compiled shaders/C++ or executed this probe.

The probe checks every face and authored mip of a constant radiance source: sky and specular retain radiance, diffuse irradiance includes PI, the split-sum BRDF LUT is finite/in range, a missing HDR preserves the published snapshot, empty source generates a default sky, blur/visibility changes share images, and old snapshots remain valid after generator cleanup. The small extents/sample counts keep this independent of RT availability.

Lead checklist:

1. Compile bg2e and `draw_cubemap_render_pass` on available Vulkan/Metal. Run the probe and example 06. Validate deployed `draw/environment/*.spv`/`.metallib` discovery in development/app bundles/installed resources. No production rendering migration is part of this step.
2. Use an asymmetric HDR with labeled axes/colors to verify all six cubemap face centers, top/bottom orientation and seams on both backends. Inspect the specular chain from roughness 0 at mip 0 through roughness 1 at its final mip. Independently generated levels must survive sky rendering and resource sharing. Compare diffuse irradiance using the documented PI convention.
3. Replace a scene EnvironmentComponent source at a stopped-producer boundary via EnvironmentGenerator::synchronize; then rebind SkyboxRenderer and renderer IBL consumers to the new snapshot. Try another HDR, empty/default source, missing input, unsupported SDR input and incompatible resource contexts. Failure preserves the previous published resources. Explicit build reloads unchanged source paths/configuration edits.
4. Set normalized blur in [0,1] and visibility, including invalid/NaN blur rejection. Reference serialize/deserialize must retain these declarative attributes without image loading. Blur-only changes share the existing GPU images.
5. Draw a skybox into HDR color plus initialized depth: foreground depth <1 must retain existing color, depth=1 receives sky, depth is never written, camera translation has no effect and camera rotation changes direction. The standalone draw runs inside an existing rendering scope; the RenderLayer record form loads supplied color/depth, renders and restores color ShaderReadOnly. Exercise window/internal-resolution resize and optional no-depth standalone rendering before foreground geometry.
6. Run with RT disabled and, when available, an HDR format lacking linear filtering/mipmap generation. The selected format's unsupported usages fail explicitly; sampled filtering falls back to nearest and source mip allocation falls back to one level. There is no RT gate or automatic SDR/failed-source substitution.
7. Replace a compatible generation tool/shader and preserve `draw.environment.*.v1` contracts, push packing, resource bindings, orientation, linear color and output semantics. Keep Engine/device alive until all passes, externally retained snapshots and submitted users are gone.
