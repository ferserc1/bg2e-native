# Update synchronization verification

`runUpdateSynchronizationProbe(delegate)` in `probe.hpp` requires an initialized default delegate with the standard deferred/final/temporal/upscaler implementations, settled environment and settings, an empty pending queue and stopped background CPU producers. It checks applied/unchanged notifications, logical invalidation, stale generations, a false catalog validity guard, adjacent coalescing, mixed callback ordering, reentrant queue snapshots and invalid values. Unsupported configurations return false. The source probe has not been compiled or executed.

Run on Metal and Vulkan. Replay the same presentations with `setValueUpdateDrainElisionEnabled(false)` and `true`; compare scene output and final settings while capturing `delegate.queuedRendererUpdateDrains`, `delegate.valueOnlyUpdateBatches`, `delegate.valueUpdatesApplied`, `delegate.valueUpdatesUnchanged`, `delegate.valueUpdatesStale`, `delegate.valueUpdatesCoalesced` and `delegate.conservativeUpdates`. The baseline keeps typed behavior and changes only drain elision. Under long GPU latency, typed-only batches should contribute no queued-update drain with elision enabled; mixed batches should retain one.

Exercise GraphicsSettingsWindow exposure/contrast/brightness/gamma sliders. Its completion explicitly opts into UI/persistence-only notifications. Test invalid values, catalog reset/rebind before prepare, facade destruction, stale renderer generations, unchanged assignments and persistence failures. Check a custom completion without opt-in, catalog extensions, custom final/temporal/upscaler implementations, multi-property imports, texture/material edits, resolution/effect changes, import/export, resize, scene replacement and cleanup: these keep the conservative route. Replacement/resource waits must remain attributable to their own initiator.

For material realization, repeat `MaterialBase::updateTextures` with identical realized source revisions: `material.realizationNoops` should rise without `material.drains.updateTextures` or upload work. Change a source texture revision and verify realization/upload/replacement waits still occur, owners remain live and failures leave the previous generation usable. Scalar source revisions must still be consumed by normal draw binding packing.

Capture separate cold-start, transition and settled steady-state profiles with backend, resolution, scene size, update class and queue latency. Attribute slot waits (`frame.acquireAndWaitSlot`), upload/queue completion and lifecycle drains separately. Compare exclusive CPU times; obtain GPU timings without adding measurement waits. Native race/validation, image parity, real drain counts and timing evidence remain pending.
