# Manual deferred renderer checks

These fixtures are source only. The agent has not compiled shaders/C++ or executed them. No CMake target is added. Use an existing draw runner with an initialized window Engine and actual acquired presentation slots, or the non-template DefaultRenderLoopDelegate. Do not invent frame slot completion or presentation serials.

1. Construct `RendererDeferred(shaderRoot)` and `deferredProbeScene(engine)` from `probe.hpp` at a stopped boundary. Initialize with the runner's output/internal extents, output format and depth D32. Call `attachScene(root)` and `setCamera(identity, identity)`. With DefaultRenderLoopDelegate, use `setScene(root)` and keep the renderer camera explicit. Direct callers call `prepareFrame()` before acquisition, then `update(frame)` and `record(frame)` outside rendering/compute scopes. Retain renderer/root/output through completion, then cleanup while Engine remains alive.
2. After submission completion, read an RGBA8 UNORM output and call `checkDeferredCenter`. It expects red opaque + blue 50% glass, with the green transparent square behind opaque depth rejected. Both transparent classes participate in one far-to-near sequence, and color correction occurs once. Repeat with odd internal/output extents (for example 127x95 -> 253x191), and both Vulkan/Metal, including a device with no RT.
3. Remove the blue square: center becomes red, not green. Move green to depth 0.1: it becomes the nearest glass. Reverse node insertion order while retaining distinct transforms: distance sorting determines composition. Test overlapping nonconvex/multiple triangles separately; sorting is per submesh with nearest surface per draw, not order-independent per-triangle transparency.
4. Set blue alpha cutoff above 0.5: it is discarded and red survives. Check visible cutout/zero-alpha texels with a checker texture and two UV sets. Repeat six texture/channel/inversion/scales/linear-vs-sRGB cases from the binding fixture. Albedo alpha remains linear, native sRGB allocations are not decoded twice, and missing AO does not mean a baked lightmap. Baked multiplier stays white.
5. Replace unlit materials with lit rough/metallic surfaces. Check omni, directional and spot cone angles in degrees, emission, Fresnel tint, sheen, and refraction against asymmetric HDR input. Rotate camera and nonuniformly scale nodes. The sky preserves opaque foreground. Linear irradiance includes PI; no second PI multiplier, tone mapping or gamma should occur in the intermediate HDR images.
6. Access `renderer.finalSettings()` after initialization. `display.x` values 0..7 select final/albedo/normal+emission/material/Fresnel+flags/sheen+refraction/white baked/depth. Debug images show the last G-buffer layer processed (opaque if no transparent items). Exposure is stops, gamma must be positive. Repeat UNORM and native sRGB outputs; displayed values agree within format precision. Modify settings and request a scene frame from the delegate.
7. Inject `CountingGBuffer`: put `{pass, {outputExtent, internalExtent, pass->contract()}}` in `RendererConfiguration.layers`. It must receive one opaque and two transparent calls per probe frame. Replace any other stage with an application-owned RenderLayer of the documented contract; sky replacements implement SkyboxPass including setCamera. Deliberately change semantic/format/extent/interface or duplicate a stage: initialization/dispatch must reject it. A final replacement need not derive FinalLayer and renders without access to the default settings API.
8. Cycle slots with different transforms/materials, resize/minimize/restore, pause/resume, scene detach/reattach, and replace the renderer with another RendererDeferred. Inspect native validation for live descriptor mutation and stale images. Resize/cleanup may wait; normal update/record must not waitIdle, upload or submit. Every intermediate target and UBO is slot-local; each transparent fullscreen draw has its own retained set.
9. Change EnvironmentComponent source/blur/visibility before the safe prepare hook. Check default sky, valid HDR replacement, missing HDR retention and `environmentError()`. Fixed `RendererConfiguration.environment` bypasses generation and is retained/validated. Stop background producers at lifecycle/prepare boundaries. Animation-driven source changes become visible at the next prepare hook.
10. Exercise exact D16 and D32 image copies in transfer layouts on both native backends, with two matching sampled depth attachments and depth rendering/read-sampling to observe results. Mismatched formats/extents/usages/layouts, overlapping copies, and depth-stencil formats remain rejected. No depth upload/readback extension is implied. Keep all production examples operational.

The full working Application example and reflected controls are M01-15/M01-12; FSR/upscaler injection and automatic internal-resolution policy are M01-13. This step already performs ordinary bilinear final reconstruction and requires no FSR/RT support.

11. Construct `RendererDeferred` with an empty `RendererConfiguration`. Verify the
   retained configuration requests `GlobalIllumination`, and the created GI and
   reflection components report `enabled() == true`. Check `available()`, status
   and `usesGlobalIllumination()`/`usesReflections()` separately on supported and
   unsupported devices; a requested default is not proof of native capability.
   Then explicitly choose IBL and disable each effect, and verify those settings
   remain authoritative. Confirm `draw_model_edit` inherits the same default and
   the explicit IBL/off configuration in `draw_lightmaps` remains unchanged.
