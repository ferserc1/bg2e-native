## Public contracts

- `ShaderStage::AnyHit`, `ShaderLib::anyHit()` (`.rahit.spv`, Vulkan `main`; optional absent Metal module), and an appended nullable `RayTracingPipelineDescription::anyHitShader` support one native Vulkan triangle hit group with closest-hit, any-hit, or both. Earlier description aggregate prefixes are preserved. Metal continues to use native compute; supplying an any-hit module to its wrapper is rejected, not emulated.
- `ResourceBinding::additionalStages` adds explicit Vulkan visibility to one unique set/binding. It does not change the module's single execution stage. Metal additional visibility must share the same native encoder domain; raygen/miss/closest-hit/any-hit all map to compute. Cross vertex/fragment visibility is not silently accepted.
- `ResourceBinding::count` is a fixed fully populated sampled-image/sampler descriptor count. Other resources remain scalar. `metalArgumentBuffer` selects an explicit Metal buffer slot (1..30 for compute/RT), with `binding.metal` interpreted as the first native `id` in that buffer. UINT32_MAX preserves direct scalar bindings. Groups share set/stage and have nonoverlapping argument IDs. Collision with direct compute buffers is rejected. Argument arrays currently target compute/RT and sampled color 2D views, not storage images, cubemaps, graphics stages or descriptor buffers.
- `ResourceSet::setSampledImages(binding, span<const ImageView>)` and `setSamplers(binding, span<Sampler* const>)` assign a whole declared array. Counts must match exactly, including valid fallback entries. Invalid/null/wrong-device/usage/type resources fail before array publication. `update()` rejects uninitialized arrays. Scalar setters remain for scalar bindings.
- `Device::resourceArrayCapabilities()` reports enabled nonuniform sampled-resource support, conservative image/sampler/per-stage counts and storage-buffer byte range. Vulkan uses enabled Vulkan-1.2 features and the minimum per-stage/descriptor-set counts. Metal requires Tier 2, caps engine image capacity at 256, samplers at min(256, native argument-buffer count), resources at 1024, and reports native buffer length. Zero/default capabilities mean unavailable, not infinite.
- `ResourceArrayCapabilities::profileCapacity(reservedImages, reservedSamplers, reservedResources)` chooses 256, 128 or 32, or zero, after reserving other effect resources. Limits include scalar bindings. Profile shader/library names must match the chosen count. This step supplies all three primitive probe profiles; actual effect libraries remain M03-04–06 work.

Use fixed arrays with every element assigned, no update-after-bind, partial binding or variable descriptor counts. No new physical-device aggregate RT flag is used to infer arrays. Pipeline creation and format requirements remain separate checks. Scene material/geometry policy and the future public snapshot builder stay in draw::pipeline, starting M03-04; GPU consumes only primitive resources. Whole storage buffers are checked against usage/device/range; packed geometry requires no new raw buffer-address or offset API.

## Native ownership and synchronization

ResourceSet borrows source owners; callers retain images/views/samplers/buffers, TLAS and referenced BLAS through submission completion. Pipeline layouts and device lifetimes remain borrowed. Descriptor/argument updates occur only at a retired slot or drained boundary. New tables belong to a new/retired ResourceSet, never an in-flight set.

Vulkan array writes resolve descriptor info pointers only after pending vectors stop growing, and initialized-binding tracking stays bounded across updates. Metal groups use native argument encoders and owned shared argument buffers. Samplers are created with argument-buffer support. Native compute/trace binding declares every indirectly referenced texture through useResource, while existing TLAS binding declares referenced primitive acceleration structures. Clean update paths reuse unchanged encoded arrays; changed arrays replace buffers only under the caller's completed-boundary contract.

Vulkan RT construction validates shader device/stage/validity, layout/device and recursion depth, constructs optional groups with actual indices, aligns handles and each SBT region's base independently, pads for the allocation's actual device address, flushes noncoherent writes, leaves missing regions zero and cleans up failed construction. Dispatch checks nonzero dimensions and native invocation/dimension limits. The primitive fixture creates a missing-miss pipeline without dispatch to cover the old hit-offset bug and rejects a wrong any-hit stage.

BLAS construction emits build-write to acceleration-build-read ordering before TLAS use. TLAS construction adds RT-stage visibility only when that device enabled pipelines, preserving query-only hardware. Vulkan rejects out-of-range 24-bit custom indices rather than masking them; both native scenes reject foreign/unbuilt meshes. Existing opacity primitives and query shader behavior are retained.

## Primitive verification fixture

[tests/gpu/advanced_tracing/README.md](../../../../tests/gpu/advanced_tracing/README.md) describes the header-only harness entry point and lead checks. Native probe shaders live in `shaders/src/draw/rt_probe` with paired shared data helpers in `shaders/src/draw/lib`. Existing paired shader discovery already recognizes rahit and preserves nested library paths; CMake is unchanged.

The fixture selects a supported 32/128/256 profile, fills every descriptor, and traces two indexed triangle submeshes. Nonzero firstIndex, a separate packed vertex base, dense TLAS identity, barycentric UV1 interpolation, divergent image and sampler selection, more than eight images and cutout rejection are observable through exact RGBA8 comparisons. Repeat/clamp behavior differs for the same image. Even-index front textures are fully transparent and must reveal the rear hit; odd-index textures produce the nearer hit. Canonical identity values differ from dense TLAS ordinals. Missing-array, wrong-count, null-resource, oversized-layout and wrong-shader-stage errors are exercised explicitly. Vulkan runs query and native pipeline paths independently when supported; Metal runs nearest-hit compute queries. Unsupported capability/format returns false and is a skip, not a pass.

Static checks performed: declarations/overrides/call sites, native metal-cpp API names, backend bindings and record packing, shader discovery and profile matching, slot/source lifetime, optional SBT regions and failure paths, source delimiters/licenses/dependency boundaries, scoped Markdown links and git diff --check. No build/configuration, shader compiler, probe dispatch, examples, tests or packaging scripts were executed. No all-device support claim is made.
