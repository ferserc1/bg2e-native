## Phase 1 implemented scope (historical)

- Added public `bg2e::plugin` headers for Plugin, PluginManager, ComponentRegistrar, SDK/descriptor, contexts, structured load/scan/unload reports, module leases and PluginComponentsVisitor, plus implementation sources and umbrella integration.
- `BG2E_DEFINE_PLUGIN` generates the C query/factory/destruction exports. `Sdk.hpp` supplies contract/SDK versions and an ABI fingerprint for architecture, compiler, standard library, CRT macros, packing, language mode, RTTI/exceptions, debug/hardening settings and selected C++ object sizes. The descriptor also verifies the resolved shared-engine identity. Version 1 requires exact descriptor size and compatibility values; public C++ ABI changes require an SDK ABI identity bump.
- Added the `BG2E_SDK_BUILD_ABI` hook for additional ABI-sensitive CMake options. Phase 2 must configure it consistently and define `BG2E_PLUGIN_BUILD` on plugin targets so Windows imports engine symbols while exporting only plugin entry points. The phase 2 helpers described below now implement this hook.
- Added generic `base::RegistrationOwner` allocation. Component insertion is non-overwriting, validates factories/IDs, reports results and supports owner enumeration/removal. Plugin registration pairs factories/reflection atomically and reports every duplicate attempt; silent overloads append names without warnings.
- Reflection types and polymorphic subtypes support non-overwriting owned contributions and owner removal. Owned metadata and executable subtype callbacks are destroyed on owner removal while the module is still loaded; consumers must discard cached pointers/copies before unloading. Revision changes reset the inspector's component selection.
- Implemented deterministic non-recursive directory discovery, recoverable errors, canonical-path/plugin-ID duplicate handling, rollback of failed contributions and allocation-free fallback statuses. Explicit loads remain outside MainLoop session ownership.
- Added `PlatformTools::pluginPath()`. MainLoop installs its session guard before discovery and constructs graphics execution afterward. Shutdown stops new work, joins async readers, discards pending callbacks, stops plugin jobs, drains GPU work, prepares plugins, calls `Application::preparePluginShutdown`, cleans delegates/UI, retires registrations, cleans the engine and finishes automatic plugins in reverse order.
- Added registrar stop callbacks for job cancellation/subscription revocation, module leases and a registry read lease. MainLoop async parsing acquires a read lease automatically; loading/unloading refuses registry mutation while readers remain active. Other background parsers must use the same lease contract.
- Implemented a visitor that includes disabled nodes and removes collected components in a separate pass via normal Node callbacks. Runtime unload requires a caller-owned stopped boundary and supports scene-root checks/removal and physical release under the programmer-owned cleanup contract.

## User-approved unload contract (supersedes the original retention policy)

- The user explicitly accepted programmer responsibility for all plugin uses before unload; missing cleanup may crash. Phase 1 feedback was implemented before phase 2.
- `Plugin` stores IDs only after successful factory/reflection registration. Duplicate, invalid and reverted contributions are omitted. `Plugin::componentTypes` exposes the list; the manager supplies a host-owned copy by ID.
- Added `Plugin::removeComponents(root)`, its static `(id, root)` facade, and `PluginManager::removeComponents(id, root)`. They include disabled nodes, remove collected matches through normal Node callbacks, and release their own temporary references before returning.
- Before explicit unload, the programmer must call cleanup for EVERY active scene and release detached objects, clones, history/selection/clipboard references, weak control blocks, cached metadata, callbacks, plugin-origin exceptions and jobs. The same obligation applies to `Application::preparePluginShutdown` for automatic modules. No automatic complete lifetime census is claimed.
- Removed registration-triggered process retention and the retained reflection/subtype storage pools. Owned executable metadata, registry factories and Plugin instances are destroyed before closing their library. Successful explicit unload now physically releases the loader reference and reports `Unloaded`; optional known module leases return `Pending` until `collect()` at a host safe point. Failed cleanup/readers still prevent physical release.
- Bumped the SDK C++ ABI identity to `bg2e-plugin-sdk-2` for the changed Plugin layout. The C bootstrap contract version remains 1.
- Documented the contract, cleanup APIs, explicit sequence, status semantics and automatic shutdown responsibilities in `doc/api/plugin/unloading.md`, linked from the plugin/API indexes and public headers. Updated phase 1/summary/documentation planning requirements to prevent reintroducing the superseded retention model.
