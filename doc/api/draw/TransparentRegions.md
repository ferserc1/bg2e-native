# Transparent processing regions

The default deferred renderer limits per-item transparent G-buffer replay and lighting composition to conservative projected bounds of uploaded rigid submeshes. Both transparent classes share a stable far-to-near order based on projected uploaded-submesh bounds centers, with object-origin fallback. Offscreen transparent raster layers can be skipped without removing tracing geometry.

Use `RendererDeferred::setTransparentRegionsEnabled(false)` for a full-screen diagnostic baseline. Uncertain bounds, depth-plane intersections, non-affine transforms, custom raster/lighting/final passes and debug views automatically retain that baseline. Regions use the jittered camera and include a raster edge guard.

The complete transparent receiver batch and its shared effects are recorded once at full extent before regional per-item color composition. G-buffer clears and scratch-depth restoration retain full extent. Scratch is seeded from unchanged preserved opaque depth before the batch and each item; actual receiver depth guides lighting and effects. No depth or effect histories are allocated per item. Regional composition first copies the complete current background to the other ping-pong target and loads it, preserving outside pixels and arbitrary refraction reads. `pipeline::RasterFrame::region` is borrowed pass coverage; replacement passes receive full coverage from this renderer. `FullscreenPass::draw` accepts an optional trailing region; direct callers must initialize the complete destination before a regional draw.

`gpu::RenderingDescription::scissor` uses top-left attachment pixel coordinates. It restricts graphics draws, preserves the full viewport and attachment clear area, and is restored at each pipeline binding. Empty/out-of-bounds scissors are rejected. This facility is implemented in both GPU backends used by production draw.

Pointwise SoftShadowPass callers can supply a conservative origin-anchored region to omit right/bottom workgroups and clear untouched output to neutral visibility. RendererDeferred records its shared transparent effect batch without an item region, so shadows, AO/GI/reflections, temporal accumulation and denoise keep complete receiver/signal/history processing. Filter and reprojection validity therefore retain the existing full-screen contract.

Area counters describe raster/composition coverage and shadow workgroup invocations, rather than GPU timing. Complete image copies/clears remain costs; depth copies add bandwidth without allocating more VRAM. See [the transparent-layer sequence](RendererDeferred.md#transparent-layer) for depth ownership and shared-effect limits. See `tests/draw/transparent_regions/README.md` for comparison procedure and counters. Native parity and GPU performance acceptance are pending.
